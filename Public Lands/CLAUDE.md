# Public Lands Event Kit -- Indivisible Project

## What It Is
A website that serves as a community event planning kit for Indivisible chapters nationwide. The goal is to make it easy for any local chapter to organize a public lands advocacy event in their area -- giving them the tools, templates, and guidance to run a successful community action.

## Audience
Indivisible chapter leaders and organizers across the country. Assume they are motivated and engaged but may not have event-planning experience. Make everything concrete and actionable.

## Purpose
- Help chapters plan and host local public lands events
- Provide reusable templates, checklists, and talking points
- Lower the barrier to organizing so more chapters take action

## Brand
- Follow Indivisible national brand when possible (see parent CLAUDE.md)
- Tone: friendly, smart, action-oriented
- Every page should have a clear next step

## Tech Stack
- Astro + Tailwind CSS
- GitHub + Cloudflare Pages
